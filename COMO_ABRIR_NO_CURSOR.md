# Como abrir no Cursor

1. Extraia a pasta `letter-platform`.
2. Abra o Cursor.
3. Escolha **File > Open Folder**.
4. Selecione a pasta `letter-platform` inteira.
5. No Windows, execute `iniciar-backend.bat`.
6. Em outro terminal, execute `iniciar-frontend.bat`.
7. Acesse `http://localhost:3000`.

Credenciais iniciais:

- `admin@letter.com.br`
- `Letter@123`

O backend ficará em `http://localhost:8000` e a documentação Swagger em `http://localhost:8000/docs`.

## Regra para as próximas fases

Não crie novas pastas de projeto por fase. Amplie sempre os domínios dentro de `backend/app` e as páginas dentro de `frontend/app`, mantendo o projeto único.

# Documentos-fonte NINA Asset

Esta pasta preserva os três documentos recebidos para a evolução v0.19.0:

- `Nina_Asset_Manual_Blindagem_2026.docx`: régua H+1/H+61, notificações, caducidade, edital e ata.
- `Nina_Asset_Edital_Master_2026.docx`: corpo proposto do edital extrajudicial.
- `Nina_Asset_Architecture_Blueprint_2026.docx`: modelagem, jobs, AVM, S3 e redução de preços.

O conteúdo foi utilizado como requisito de produto. Afirmações jurídicas, registrais e regulatórias continuam sujeitas a parecer profissional e não são tratadas como autorização automática de produção.
